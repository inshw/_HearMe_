# 🛡️ HearMe: AI Companion

**HearMe** is a sleek, voice-first safety app providing calm, immediate support. Built with **Gemini 3 Flash Preview**, it offers cutting-edge transcription and safety reasoning wrapped in a high-end dark mode interface.



## ✨ Core Features
* **🎙️ Smart Voice:** Hands-free communication via Streamlit's audio input.
* **🧠 Gemini 3 Powered:** High-speed transcription and brief safety reasoning.
* **🗣️ ElevenLabs Voice:** Converts AI text into human-like, soothing audio.
* **🚨 Quick-Action:** Rapid access buttons for 911 and 211.
* **🛰️ GPS Status:** Visual "Live Tracking" indicator for peace of mind.

## 🚀 Quick Setup
* **API Keys:** Set `GEMINI_API_KEY` and `ELEVEN_API_KEY` in your `.env` file.
* **Run:** `python -m streamlit run voicenai.py`

## 🛠️ Tech Stack
* **Frontend:** Streamlit (Custom Dark CSS)
* **Brain:** Gemini 3 Flash Preview
* **Voice:** ElevenLabs API
